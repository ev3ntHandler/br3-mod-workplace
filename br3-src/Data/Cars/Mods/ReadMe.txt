------------------------------------
-- About texture modding
------------------------------------
* Each car (except boss cars) has 2 textures - the default one is included and can be used as a template.
* Boss cars have only 1 texture - these cars are BT One, Hound, Sunstorm, PetiteXs, Tank, Coyote
* You can only access the second skin once you have unlocked it in-game.
* If you want to have a second skin rename it to XXXXXXSkin2_Texture.png.
	For example PhaserGTISkin2_Texture.png
* Textures need to be in .png format and 1024x1024 in size. 
* Have fun!
